# Spite (archived)

This repository is archived and no longer updated. Spite now lives in the
[Spite-Language](https://github.com/Spite-Language) organization, split into one repository per part:

| Repository | What it holds |
| --- | --- |
| [spite_documentation](https://github.com/Spite-Language/spite_documentation) | Why Spite exists, the tutorial and the skill for language models: start here |
| [spite_compiler](https://github.com/Spite-Language/spite_compiler) | The compiler, written in Spite and compiling itself |
| [spite_standard_library](https://github.com/Spite-Language/spite_standard_library) | The standard library |
| [spite_spec](https://github.com/Spite-Language/spite_spec) | The test suite every claim about the language runs in |
| [spite_benchmarks](https://github.com/Spite-Language/spite_benchmarks) | Plain Spite programs measured against hand-tuned C |
| [mortaros_spite](https://github.com/Spite-Language/mortaros_spite) | The decisions behind every rule of the language |

The history here stays readable, but issues, pull requests and new work belong in the repositories above.
