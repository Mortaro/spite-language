# Decisions

Every language decision, in the order it was made. A decision lives twice: in the page that teaches that part of
the language, which is where the rule is normative, and as a row here, which says when it was made, by whom and
why. A decision that exists only in a conversation will be re-litigated.

**The log is append-only.** A row is never edited, renumbered, reordered or removed. A decision that changes an
earlier one is a new row that names the one it supersedes ("superseding D9"), and the page that teaches the rule
is changed to match.

**How to add a row:** append one line at the end of the table -- `| date | **Dnnn** (decided by Mortaro): what was
decided, in a sentence or two, and why |`, with the next free number. A proposal an agent makes is written
"(proposed by Claude, unconfirmed)" and never recorded as decided; a row that only builds a decision says so,
"(implements D157; ...)". Then put the rule itself into the page that teaches it, in the same commit. With more
than one agent running, edit this file only by appending, match on the surrounding text rather than on line
numbers, and re-read it immediately before writing it (`AGENTS.md`).
